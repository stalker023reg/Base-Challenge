# Base Challenge

Base Challenge is a social sports challenge platform built on Base.

The project allows users to create sports competitions, challenge friends or the community, compete for rewards, and earn onchain achievements.

## Features

* Strava integration for activity verification
* ETH and USDC reward pools
* Soulbound achievement badges
* Ethos Score reputation integration
* Public and private challenges
* Secure escrow system
* Community leaderboards

## Vision

The goal is not to create another fitness tracker.

Base Challenge aims to build an onchain sports ecosystem where achievements, reputation, and rewards become part of a user's digital identity on Base.

## Technology Stack

* TypeScript
* Next.js
* Base
* Base Sepolia
* PostgreSQL
* Strava API
* Ethos API
